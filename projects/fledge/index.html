PROJECT / POWERSHELL / WINDOWS FORENSICS

FLEDGE

The Forensic Live Evidence Data Gathering Engine

OVERVIEW

Project Overview

FLEDGE explores the development of a lightweight PowerShell-based workflow for efficiently collecting and documenting live data from Windows systems.

OBJECTIVES

Design Goals

01

Structured live forensic collection

02

Automated hashing and integrity verification

03

Clear collection logging and documentation

04

Portable execution from removable media

05

Repeatable collection methodology

DEVELOPMENT

Project Status

This project is currently under development. Technical documentation, methodology, testing results, and source material will be published as development progresses.
